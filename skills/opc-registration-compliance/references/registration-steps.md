# 注册步骤与材料清单

> 依据：《中华人民共和国市场主体登记管理条例》（国务院令第746号）https://www.gov.cn/zhengce/zhengceku/2021-08/24/content_5632964.htm ；《中华人民共和国公司法》（2023 修订）http://www.npc.gov.cn/npc/c2/c30834/202312/t20231229_433999.html 。信息核实日期：2026-10-22。不构成法律意见。

## 1. 准备登记事项（条例第八条）
| 事项 | 说明 | 用户填写 |
|---|---|---|
| 名称 | 只能登记一个名称，由申请人依法自主申报（第十条）；公司名称须标明"有限责任公司"或"有限公司"字样（公司法第七条） | |
| 主体类型 | 个体工商户 / 个人独资企业 / 有限责任公司 | |
| 经营范围 | 分一般经营项目和许可经营项目；按登记机关公布的经营项目分类标准填写；许可项目需在申请登记时提交批准文件（第十四条） | |
| 住所或主要经营场所 | 只能登记一个（第十一条）；省级政府可作出更便利的具体规定（第十一条第三款）——工位注册、集中登记地等以当地官方规定为准 | |
| 注册资本或出资额 | 实行认缴登记制，以人民币表示；不得以劳务、信用、自然人姓名、商誉、特许经营权或者设定担保的财产等作价出资（第十三条） | |
| 法定代表人 / 负责人 / 经营者 | 第十二条列明不得担任法定代表人的情形 | |
| 按类型另需登记 | 有限公司股东姓名；个人独资企业投资人姓名及居所；个体工商户经营者姓名、住所、经营场所（第八条） | |

## 2. 备案事项（条例第九条，节选）
章程、经营期限、股东认缴出资数额、董事监事高级管理人员、登记联络员、受益所有人相关信息等。

## 3. 申请材料（条例第十六条）
- [ ] 申请书
- [ ] 申请人资格文件、自然人身份证明
- [ ] 住所或者主要经营场所相关文件
- [ ] 公司章程（设立公司时）
- [ ] 国务院市场监督管理部门规定的其他材料（具体清单以登记机关公开的材料清单为准）

实名登记：申请人应当配合登记机关核验身份信息（第十五条）。可以委托其他自然人或中介机构代办（第十八条）。

## 4. 办理与领照
- 材料齐全、符合法定形式的，予以确认并当场登记；不能当场登记的，应当在 3 个工作日内予以登记；情形复杂的，经批准可以再延长 3 个工作日（第十九条）
- 营业执照签发日期为成立日期（第二十一条）；电子营业执照与纸质营业执照具有同等法律效力（第二十二条）
- 办理入口：国家政务服务平台 https://gjzwfw.www.gov.cn/ 或当地市场监管部门 / 政务服务网（以当地为准）

## 5. 领照后常见事项（具体流程以当地为准，本 skill 未收录原文）
- 刻制印章、开立银行账户、税务相关事项、社保相关事项：**待核实，请向当地主管部门或银行确认**
