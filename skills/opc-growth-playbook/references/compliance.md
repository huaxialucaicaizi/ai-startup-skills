# 合规检查（推广内容）

> 本清单只列已核实官方原文的条款，不构成法律意见。平台规则以各平台官方规则为准。信息核实日期：2026-10-22。

## 1. 广告标识
《互联网广告管理办法》（国家市场监督管理总局令第72号，2023-05-01 起施行）第九条：互联网广告应当具有可识别性，能够使消费者辨明其为广告；通过知识介绍、体验分享、消费测评等形式推销商品或者服务，并附加购物链接等购买方式的，广告发布者应当显著标明"广告"。
原文：https://www.gov.cn/zhengce/202305/content_6858084.htm

- [ ] 接受品牌合作、或"体验分享 + 购买链接"形式的内容，显著标明"广告"
- [ ] 广告主对广告内容的真实性负责（同办法第十三条）

## 2. 直播带货
同办法第十九条：商品销售者或者服务提供者通过互联网直播方式推销商品或者服务，构成商业广告的，应当依法承担广告主的责任和义务。
- [ ] 直播中对产品功能、效果的说法有依据

## 3. AI 生成内容标识
《人工智能生成合成内容标识办法》（2025-09-01 起施行），发布说明：https://www.cac.gov.cn/2025-03/14/c_1743654685899683.htm
- [ ] 使用 AI 生成的图片、视频、声音、数字人时，按办法和平台要求标识（具体要求以原文和平台规则为准）

## 4. 真实宣传（本 skill 规则）
- [ ] 不编造用户数、效果数据、客户案例
- [ ] 未上线产品如实写"内测 / 等待名单"
- [ ] 用户评价截图已获授权，并隐去个人信息
