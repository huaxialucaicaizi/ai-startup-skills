# 口播脚本结构

| 段落 | 作用 | 写法提示 |
|---|---|---|
| 开头钩子 | 让目标用户停下来 | 直接说出目标用户的具体场景或问题；不用夸大或恐吓式表达 |
| 痛点场景 | 让用户觉得"说的就是我" | 一个具体场景，来自访谈或真实经历 |
| 方案演示 | 展示怎么解决 | 录屏或实操；未上线产品如实说明是"内测 / 等待名单" |
| 证据 | 建立信任 | 真实案例、过程数据、用户反馈截图（需授权）；没有就写"待补充"，不编 |
| 行动引导 | 下一步做什么 | 只放一个：关注 / 领取资料 / 私信关键词 / 加入等待名单 |

输出格式：

| 段落 | 时长（实测后填写） | 口播文字 | 画面 / 字幕 |
|---|---|---|---|

- 时长以用户实际录制计时为准，不预设语速。
- 使用 AI 生成的画面、声音或数字人时，按 `compliance.md` 中的 AI 生成内容标识要求处理。
