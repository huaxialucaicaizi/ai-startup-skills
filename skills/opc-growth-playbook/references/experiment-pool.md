# 增长实验池

## 实验卡

| 字段 | 内容 |
|---|---|
| 编号 / 名称 | |
| 针对漏斗哪一层 | |
| 假设 | 如果 ___，那么 ___ 会提高，因为 ___ |
| 做法 | 具体做什么、在哪个平台、做几条 |
| 指标 | 只看一个主指标 |
| 判断标准 | 和自己的基线比，达到 ___ 算有效（建议值，可自行调整） |
| 周期 | 例如 1–2 周（建议值，可自行调整） |
| ICE 评分 | 影响 _ / 信心 _ / 容易度 _（各 1–5 分，用户自评） |
| 结论 | 继续 / 调整 / 停止（复盘时填写） |

## 排序与节奏
- 按 ICE 总分排序；同分时优先解决"最弱的一层"。
- 每周同时跑的实验建议不超过 2–3 个（建议值，可自行调整），避免分不清是哪个起作用。
- 一次只改一个变量（如标题、封面、开头钩子、发布时间、行动引导）。

## 常见实验方向（只是方向，不代表效果）
- 曝光：选题角度、标题、封面、开头钩子的写法
- 互动：结尾提问、清单 / 模板类内容、评论区回复
- 留资：资料包、免费诊断、等待名单
- 付费：限时试用、案例展示、人工一对一演示
