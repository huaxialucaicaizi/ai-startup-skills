# 定价方法

## 第一部分：成本法（算底价）

| 成本项 | 单次 / 单月数值 | 来源 | 查询日期 |
|---|---|---|---|
| 模型 / API 调用费（按单次任务的调用量估算） | | 服务商官方价格页 | |
| 工具订阅分摊 | | 账单 | |
| 外包 / 第三方服务 | | 合同 / 报价 | |
| 自己的时间：小时数 × 期望时薪 | | 用户自定 | |
| **单位成本合计** | | | |

- 底价 = 单位成本 ÷（1 − 目标毛利率）。目标毛利率由用户自定，标"建议值，可自行调整"。
- 模型价格会调整，必须来自服务商官方价格页并写查询日期；查不到就写"待补充"。
- 订阅制产品：按"重度用户"的调用量也算一遍，确认重度用户不会亏钱。

## 第二部分：竞品法

| 竞品 / 替代方案 | 公开价格 | 包含什么 | 来源链接 / 截图 | 查询日期 | 我多了 / 少了什么 |
|---|---|---|---|---|---|

- "替代方案"包括通用 AI 产品、外包、客户自己做（时间成本）。
- 只写能查到来源的价格；不写"市场价一般是……"。

## 第三部分：价值法

| 项目 | 客户自己的估算 | 证据状态 |
|---|---|---|
| 每次 / 每月节省时间 | | 用户自述 / 访谈记录 |
| 多赚 / 少花的钱 | | 用户自述 / 访谈记录 |
| 价格上限参考 = 价值 × 用户自定比例 | | 建议值，可自行调整 |

## 第四部分：输出价格区间

| 底价（成本法） | 建议价 | 上限参考（价值法） | 依据 |
|---|---|---|---|

判断：
- 建议价低于底价 → 先降成本或调整交付范围，不建议亏本卖。
- 缺任何一项 → 该项写"待补充"，并说明补齐后再定。
