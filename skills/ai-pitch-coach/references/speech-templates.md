# 3 / 5 分钟讲稿结构

时间分配是排练参考，以主办方规定和实际计时为准。

## 3 分钟（初筛 / 快速路演）
| 段落 | 时间 | 内容 |
|---|---|---|
| 开场 | 0:00–0:20 | 一句话说清：我们为 ___ 解决 ___ |
| 痛点 | 0:20–0:50 | 一个具体场景 + 一个有来源的事实 |
| 方案与演示 | 0:50–1:50 | 产品怎么用，最好有 1 张截图或 10 秒演示 |
| 进展 | 1:50–2:30 | 最硬的进展：用户、收入、合同、获奖（只写真实的） |
| 诉求与落地 | 2:30–3:00 | 需要园区 / 大赛提供什么；一句与政策方向的契合（只用有官方出处的政策）；落地计划 |

## 5 分钟（园区入驻 / 大赛初赛、复赛常见）
| 段落 | 时间 | 内容 |
|---|---|---|
| 开场 | 0:00–0:20 | 一句话定位 |
| 痛点与用户 | 0:20–1:00 | 谁、在什么场景、现有方案为什么不行 |
| 产品与技术 | 1:00–2:15 | 核心功能、技术或方法的差异、知识产权 / 开源 |
| 市场与竞品 | 2:15–2:55 | 目标市场（标来源）、3 个竞品及差异 |
| 商业模式与进展 | 2:55–3:50 | 谁付钱、已有收入或试点、里程碑 |
| 团队 | 3:50–4:20 | 创始人为什么能做成；一人公司讲清 AI 工作流和合作方 |
| 诉求与落地 | 4:20–5:00 | 申请的支持、用途、与区域产业 / 政策方向的契合、落地承诺 |

## 排练清单
- [ ] 计时排练至少 3 遍，留 10% 余量
- [ ] 每个数字能说出来源
- [ ] PPT 每页一个重点，字号现场可读
- [ ] 演示有录屏备份（防断网）
- [ ] 准备 30 秒版本应对临时压缩时间
- [ ] 答辩准备好"不知道就说待核实、会后补充"
