# 申报材料通用清单

> 通用模板，具体以每项政策的申报指南为准。状态分三种：`[x]` 已有证明 / `[~]` 用户自述、待提供证明 / `[ ]` 待补充。

## 主体与身份
- [ ] 营业执照 / 统一社会信用代码（未注册写"待补充：计划注册时间"）
- [ ] 法定代表人 / 创始人身份证明
- [ ] 社保缴纳证明（青年人才类政策常以首次缴社保时间为准）
- [ ] 学历学位证明、留学回国证明（如适用）

## 项目与经营
- [ ] 商业计划书（BP）或项目介绍（可用 business-plan-skill 生成）
- [ ] 产品演示：截图、视频、可访问链接
- [ ] 经营数据：收入、用户、合同（只写实际数据，标明统计口径和时间）
- [ ] 融资证明：投资协议、到账凭证（如有）

## 创新能力与荣誉
- [ ] 知识产权：专利、软著、商标
- [ ] 获奖与竞赛证明
- [ ] 开源贡献：仓库链接、star 数（注明统计日期）、社区影响力证明
- [ ] 媒体报道、合作方证明

## 空间与场景
- [ ] 入驻协议或意向空间
- [ ] 场景应用证明：试点合同、用户证明

## 自检
- 每个数字都有来源吗？
- 证明材料的主体名称与申报主体一致吗？
- 是否在有效期和申报时间窗口内？
