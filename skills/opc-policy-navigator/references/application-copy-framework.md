# 申报文案框架

政府材料用客观第三人称，少形容词，多事实。未知内容写"待补充"。

1. **申报主体概况**：名称、成立时间、注册地、主营业务、团队规模（一人公司如实写"创始人 + AI 工作流"，不要虚报人数）
2. **项目简介（100–300 字）**：解决什么问题 → 为谁 → 怎么做 → 目前进展
3. **与政策方向的契合度**：逐条对应政策原文表述（例："对在人工智能开源社区建设……表现杰出的创新创业人才"），用事实证明契合，不要直接照抄政策口号
4. **创新性与技术能力**：核心技术或方法，知识产权，开源贡献（数据注明日期）
5. **市场与经营情况**：目标客户、收入或用户（实际 / 估算要分开标注）
6. **资金或资源使用计划**：申请的支持用于什么、产出什么里程碑
7. **预期成效**：可衡量的指标，只写能兑现的目标
8. **附件清单**：对照 materials-checklist.md

需要扩写 2–5 部分时，优先使用用户已有的 BP 内容保持口径一致；也可选用 BP 工具（如 business-plan-skill）辅助扩写。
