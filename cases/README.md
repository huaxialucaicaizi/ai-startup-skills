## 标注规则

- **真实案例（作者经历）**：只写作者公开过、可以归属到作者本人的事实。
- 作者自述但本仓库没有第三方核实的说法，原文标「作者自述」。
- 不知道的数字一律写「未公开」或「待作者补充」，不估算、不补一个看起来合理的数。
- 不写用户评价、收入、转化率、Star 数等没有公开来源的数字；Star 数以 README 顶部实时徽章为准。
- 不涉及前雇主的内部数据和非公开做法。案例里的「可复用动作」是本工具包的方法，不是对前雇主内部流程的复述。
- 虚构示例不放在这里，放在各子 skill 中并标注「虚构」（例如 `skills/business-plan-skill/examples/`）。

## 每个案例的结构

1. 标题和标注
2. 对应步骤（链接到 `skills/` 下的子 skill）
3. 背景
4. 做了什么
5. 可复用动作清单
6. 风险 / 注意
7. English summary
